# Setup notes

Acme Precision shop-floor setup notes, kept by the lead machinists. Read the
section for the machine before the first part of every job.

## HAAS-VF2 (vertical mill)

P-1001 gripper bracket: hold the part in soft jaws, never serrated jaws, so the
anodize faces aren't marked. Indicate the fixed jaw to within 0.01 mm before the
first part. Use the 12 mm three-flute end mill for the pocket and a fresh
chamfer tool every 200 parts.

P-2001 op 20 (cross holes): use the V-block fixture and the 6 mm stub drill.
Check the first hole position with the CMM before running the batch.

## HAAS-VF4 (vertical mill)

P-1002 motor mount plate: clamp on the vacuum table. Run the 50 mm face mill at
8,000 rpm. If the VF4 is down, the job can move to the VF2 with the same program
and a 15% slower feed.

## OKUMA-LB3000 (lathe)

Warm up the spindle for 15 minutes before the first part of the day. Thermal
growth drifts diameters by up to 0.02 mm in the first quarter hour.

P-2001 pump shaft (SS316): use the steady rest for anything over 200 mm long.
Run the coolant at 8% concentration and check it with the refractometer at the
start of each shift. Use the CNMG insert in the 1105 grade for roughing.

P-2002 impeller hub: chuck on the bore with soft jaws; finish the face last.

## AMADA-HG1303 (press brake)

P-3001 and P-3002 (CRS 14 ga): use the 30 mm V-die. Measure the first bend
angle with the digital protractor; tolerance is ±0.5°.

## DEBURR-1

Break all sharp edges 0.2 to 0.4 mm unless the drawing says otherwise. Medical
parts (Cobalt Medical) are deburred by hand only, no tumbling.
